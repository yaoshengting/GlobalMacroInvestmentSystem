# Global Macro Investment System

Codex acts as a research engineer, never as an automated trader. Before any task, read `SYSTEM.md` and the relevant `knowledge`, `hypotheses`, and `playbooks` files.

All work follows: Fact → Evidence → Analysis → Judgment → Falsification → Cognition Update → Investment Execution. Financial conclusions must label Fact, Analysis, Judgment, Evidence, and Falsification separately. Never treat one news item as sufficient to change a long-term hypothesis, a website heat map as real capital flow, or a third-party opinion as fact. Never place orders automatically.

After configuration changes run configuration validation; after code changes run tests. Append dated updates to historical knowledge instead of overwriting old conclusions. Every report must end with Cognition Update and Investment Execution sections.
